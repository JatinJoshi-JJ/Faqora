# ✦ FAQORA 🌟

A premium, interactive FAQ and Knowledge Base web application designed with elegance and performance in mind. FAQORA features a stunning 4D kinetic particle typography engine, fluid accordion transitions, and a seamless dual-mode (Light/Dark) viewing experience.

## ✨ Features

- **4D Kinetic Particle Typography:** Experience a dynamic, physics-driven interactive canvas that morphs words into stunning particle animations. 💥
- **Smooth Momentum Scrolling:** Powered by [Lenis](https://github.com/studio-freight/lenis), ensuring buttery-smooth navigation across the entire page. 📜
- **Interactive FAQ Accordion:** Beautifully animated accordions with both "Single Open" and "Multi Open" modes. 📝
- **Live Search & Filtering:** Instantly find answers using keyword search and category filters. 🔍
- **Dual Theme Support:** Seamlessly toggle between a warm "Light Mode" and a refined "Midnight Editorial" Dark Mode. 🌗
- **Audio Feedback:** Subtle, pleasant sound effects for interactions, with the ability to mute. 🎵
- **Fully Responsive:** Designed to look amazing on desktops, tablets, and mobile devices. 📱
- **Sleek UI:** Completely hidden scrollbars with retained scrolling functionality for a highly immersive experience. ✨

## 🛠️ Technologies Used

- **HTML5:** Semantic and accessible structure. 🏗️
- **CSS3:** Custom properties (CSS variables), grid/flexbox layouts, smooth transitions, and glassmorphism effects. 🎨
- **Vanilla JavaScript (ES6+):** Logic for physics simulations, state management, search, and UI interactions without any heavy frontend frameworks. ⚡
- **Canvas API:** High-performance rendering for the particle typography engine. 🖌️
- **Lenis API:** Momentum scrolling. 🛹

## 🚀 Getting Started

Since FAQORA is built using pure HTML, CSS, and JS, getting started is incredibly simple! No build tools or package managers required.

1. **Clone the repository** (or download the source code):
   ```bash
   git clone https://github.com/JatinJoshi-JJ/Faqora.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd faqora
   ```
3. **Run the project:**
   Simply open the `index.html` file in your favorite web browser!
   *(Tip: Use VS Code's "Live Server" extension for the best development experience).*

## 🎮 How to use the Particle Engine

- **Morphing Words:** Type any word in the input bar and watch the particles dynamically rearrange themselves! 🔠
- **Physics Solvers:** Switch between different physics behaviors like *Repulsion Scatter*, *Gravitational Vortex*, *Liquid Viscosity*, and *Harmonic Wave*. 🌊
- **Disperse:** Click the "Disperse" button or click anywhere on the canvas to trigger a radial shockwave! 💥
